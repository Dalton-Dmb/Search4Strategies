# AlphaIQ™ Final Release Report Template

## Release identity
Record release ID, commit SHA, deployment manifest fingerprint, build/CI reference and requested deployment mode.

## Scope completed
State exactly which KPM/ALPHA milestones are implemented, empirically evidenced, independently audited and authorised. Keep those status words distinct.

## Evidence summary
Describe historical sources/coverage, certified strategies, fold design, OOS sample sufficiency, regime×strategy×instrument findings, mismatch degradation, robustness/uncertainty, execution assumptions and limitations. Link/fingerprint underlying manifests rather than copying unverifiable headline results.

## ML summary
If enabled, record model/dataset/training manifests, OOS/calibration/abstention diagnostics, champion approval, drift baseline and rollback candidate.

## Paper/shadow summary
Record observation period, decision count, abstentions, outcomes, execution-quality telemetry, incidents and reconciliation/restart tests.

## Risk/execution readiness
Record independent veto tests, exposure/drawdown controls, lifecycle/reconciliation and recovery results. Do not disclose secrets.

## Audit
Record independent reviewer, dossier reference and all findings. Any open HIGH/CRITICAL item must be explicit and block the applicable release.

## Deployment
Record container digest, configuration fingerprint, Contabo reproduction, health/readiness, persistence, backup/restore and rollback evidence.

## Approval and limitations
Record owner-approved mode. State unresolved limitations. If LIVE is not explicitly approved, state that it remains blocked.
