# AlphaIQ™ Canonical Project Objective

Build one production-grade, auditable system that identifies prevailing market regime, evaluates a configurable multi-instrument/multi-timeframe universe, routes only certified strategies appropriate to the evidence, applies independent risk controls, journals every decision/outcome, learns through governed ML and empirical analytics, accounts for event/abnormal-market context, and can progress through research, replay, paper, shadow and explicitly authorised live deployment without architectural rewrite.

Gold receives deliberate research priority while the system remains multi-asset. Instrument/strategy/broker specialisation must emerge from reproducible evidence and configuration rather than hard-coded assumptions.
