# AlphaIQ™ Timeframe Handoff

Default hierarchy:

- Context/regime: D1 → H4 → H1
- Primary thesis/operating timeframe: H1
- Setup refinement: M30
- Execution refinement: M15
- M5: only for engines whose approved logic genuinely requires it

Do not force every strategy through every timeframe. Each certified adapter declares the observations it requires. All cross-timeframe joins must obey close-time visibility: e.g. an H1 bar that closes at 11:00 cannot inform a 10:45 M15 decision.

Historical evidence must preserve the actual timeframe graph used by each decision so productivity comparisons can distinguish thesis and entry timeframe rather than collapsing everything into M15.
