# AlphaIQ™ Evidence Archive Policy

For each material evidence/release run, retain immutable references to code/configuration, dataset manifest/fingerprint, feature/regime/strategy/model versions, fold assignment, empirical/statistical policies, generated OOS/shadow reports and audit/release decisions. Prefer machine-readable artifacts alongside human reports.

Do not overwrite prior evidence when parameters or source data change; create a new run/version. Respect data licensing by storing manifests/fingerprints and retrieval procedures when raw data cannot legally reside in the repository.
