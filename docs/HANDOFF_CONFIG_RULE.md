# AlphaIQ™ Configuration Governance

Configuration that changes strategy eligibility, regime thresholds, statistical gates, instrument universe, timeframe graph, risk, broker routes, model selection or deployment mode is evidence-relevant and must be versioned/fingerprinted in applicable manifests.

Do not hide material behavior in environment-specific code branches. Secrets belong in runtime secret injection; non-secret behavior belongs in explicit validated configuration. Historical evidence must identify the configuration under which it was generated.
