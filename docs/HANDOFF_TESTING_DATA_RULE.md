# AlphaIQ™ Testing Data Rule

Synthetic fixtures and handcrafted bars are encouraged for deterministic unit, boundary, leakage and recovery tests. They must be labelled as fixtures and must never be included in empirical/OOS performance claims or model promotion datasets unless a clearly separate synthetic-data research policy is explicitly approved.

The successor should maintain a hard conceptual and artifact boundary between **test fixtures** and **genuine historical/shadow evidence**.
