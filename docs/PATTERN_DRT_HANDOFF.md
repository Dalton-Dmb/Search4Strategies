Implement approved contemporary session/day range construction, breakout/rejection/range-location features and explicit session calendar/timezone semantics. Keep session/day DRT concepts distinct from weekly/monthly extremes. Diagnose missing bars. For both: version source definitions/parameters, require no-lookahead/deterministic replay tests, and do not invent missing proprietary thresholds.
