# AlphaIQ™ Finality Assertions

A final release should be able to answer “yes, with evidence” to these questions:

1. Can every decision be reconstructed point-in-time without future leakage?
2. Can every active strategy be traced to an exact certified source/version?
3. Can OOS results be reproduced from immutable manifests without train/validation contamination?
4. Are uncertainty, drawdown, excursions and execution assumptions visible?
5. Is ML, if enabled, governed/calibrated/rollback-capable?
6. Can risk independently veto every strategy/model?
7. Can the service recover/reconcile after restart without duplicate actions?
8. Can a fresh Contabo host reproduce the release from documentation?
9. Has an independent reviewer completed the applicable audit evidence?
10. Is the requested deployment mode explicitly approved, with LIVE otherwise blocked?

A “no” identifies an unfinished gate, not an invitation to weaken the assertion.
