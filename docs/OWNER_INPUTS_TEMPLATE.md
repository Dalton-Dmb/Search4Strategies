# AlphaIQ™ Owner Inputs — Successor Template

The successor should request these only when the corresponding work is reached and the information is not already available.

## Strategy source package
For each proprietary engine: strategy ID/name; authoritative source file/text; source version/date; approved parameters/defaults; intended timeframe graph; known invalidation/abstention rules; owner certification approval after tests.

## Historical evidence source
Provider/file source; permitted instruments; available date range; native timezone; bar/tick granularity; licensing/storage restrictions; authentication supplied out-of-band; known symbol aliases.

## Paper/shadow broker integration
Broker/account environment; demo/paper endpoint or terminal; symbol aliases; execution constraints; credentials supplied out-of-band; explicit confirmation that testing is non-live.

## Contabo deployment
Host/IP and SSH access supplied out-of-band; OS/version; DNS/TLS requirements if any; backup destination; monitoring destination; deployment mode. Do not place passwords, API keys or private keys in GitHub.

## Release decision
Requested mode: research / paper / shadow / live. LIVE additionally requires evidence and audit gates plus explicit owner authorisation; absence of approval means LIVE is disabled.
