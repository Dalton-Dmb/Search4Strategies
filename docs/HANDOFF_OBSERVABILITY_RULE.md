# AlphaIQ™ Operational Observability Rule

A deployed service should expose enough non-secret health/readiness and structured telemetry to distinguish: process running; data feed healthy/stale; feature/regime pipeline ready/abstaining; strategy registry/certification state; risk gate state; journal/storage health; broker adapter connectivity in applicable non-live/live modes; and release mode/gate status.

Monitoring must not encourage bypassing abstention or fail-safe gates merely to keep a “green” dashboard. A healthy system may legitimately be healthy-and-abstaining.
