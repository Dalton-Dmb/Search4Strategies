# AlphaIQ™ Successor Delivery Format

At project completion, deliver:

1. **Release repository state:** exact commit/tag and green CI.
2. **Evidence bundle:** immutable manifests/fingerprints and OOS/robustness reports.
3. **Strategy certification register:** exact sources/versions/tests/approvals.
4. **ML governance bundle:** only if ML enabled/promoted.
5. **Paper/shadow report:** traceable to journal decisions/outcomes.
6. **Independent audit dossier:** reviewer and findings.
7. **Deployment package:** image digest, compose/service config, non-secret env template, health/recovery, Contabo runbook.
8. **Release manifest:** complete lineage and gate results.
9. **Operations guide:** monitoring/logs/start-stop/backup/restore/upgrade/rollback.
10. **Limitations/open items:** explicit; no concealed partial completion.

Do not hand back only source code or a screenshot of a backtest.
