# AlphaIQ™ Owner Handoff Note

The successor developer should be able to work from this repository package without requiring the owner to reconstruct the project's history. The owner should normally be contacted only for exact missing proprietary strategy logic, external data/broker/Contabo access, genuinely material risk/product decisions, independent-review arrangements and explicit deployment-mode approval.

The owner should expect the successor to distinguish engineering completion from empirical certification and to provide reproducible evidence rather than headline backtest claims. The intended deliverable is one coherent AlphaIQ™ release candidate and Contabo deployment package, not a collection of unrelated scripts.
