# AlphaIQ™ Successor Quality Bar

Production-ready work should be typed/validated where appropriate, deterministic where required, modular, documented, test-covered, observable and fail-safe. Tests should include failure/abstention paths, not only happy paths. New external integrations need timeouts/error classification/recovery semantics and must not corrupt evidence lineage.

Prefer explicit versioned policy/configuration to magic numbers. Prefer immutable evidence manifests to informal notes. Prefer small reviewable PRs to opaque bulk rewrites, while maintaining one coherent release target.
