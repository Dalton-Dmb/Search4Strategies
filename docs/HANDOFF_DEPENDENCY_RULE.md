# AlphaIQ™ Evidence Dependency Rule

Do not invert these dependencies:

**approved source + genuine data → certified point-in-time decisions → labelled outcomes/OOS evidence → ML training/promotion → shadow/audit/release**.

Packaging, tests and broker-neutral integration can proceed in parallel, but they cannot substitute for an upstream evidence dependency. Synthetic fixtures are appropriate for unit/integration tests; they are not a substitute for genuine empirical validation.
