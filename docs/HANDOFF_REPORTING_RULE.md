# AlphaIQ™ Successor Reporting Rule

Progress reports should state concrete artifacts completed since the previous report: PR/commit, tests/CI, evidence run/fingerprint, deployment test, or exact blocker. Do not describe idle time as development progress and do not imply work continued while no execution environment was active.

For unresolved work, distinguish “code implemented,” “evidence run completed,” “independently audited,” and “release authorised.”
