# AlphaIQ™ Event/Abnormal-Market Handoff Note

The event layer is provider-neutral and should remain research/evidence driven. When real calendar/news/event data is connected, preserve point-in-time publication/availability timestamps, severity/source provenance, surprise inputs where legitimate, event windows and abnormality observations.

Do not use revised macro data as if it were known at the original decision time. Event context should support regime/strategy research, blackout/risk policies and later ML features only under explicit versioned rules; missing event data must be visible as missing/unknown rather than silently assumed normal.
