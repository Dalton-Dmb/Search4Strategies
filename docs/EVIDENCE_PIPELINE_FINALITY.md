# AlphaIQ™ Evidence Pipeline Finality

The successor must be able to trace an OOS intelligence row back through this chain:

`release → code/config → evidence run → dataset manifest → canonical bars → point-in-time snapshots → feature spec/provenance → regime evidence → certified strategy source/version → decision → observed outcome/excursions/execution assumptions → fold → empirical cell → robustness diagnostics → OOS productivity/mismatch report`

A missing link invalidates a reproducibility claim. Train/validation rows must never enter the OOS intelligence report. An uncertified strategy must never enter executable empirical evidence. Higher-timeframe data must not become visible before its bar closes. Event context must be point-in-time and versioned where used.

The first genuine end-to-end evidence run is a major successor milestone and should be archived with its deterministic fingerprints before ML training is promoted.
