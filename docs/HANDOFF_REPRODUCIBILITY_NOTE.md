# AlphaIQ™ Reproducibility Handoff Note

Given the same immutable code/configuration, permitted historical source snapshot, feature/regime/strategy/model versions and evidence-run manifest, a successor/reviewer should be able to reconstruct the same deterministic pre-trade decisions and fingerprints. Randomised statistical/ML procedures must record seeds and policies.

Execution simulation assumptions, bootstrap policy and annualisation must be explicit. If licensed raw data cannot be redistributed, retain provider/source identifiers, coverage, permitted fingerprints/manifests and documented retrieval/normalisation procedure sufficient for an authorised reviewer to reproduce the dataset.
