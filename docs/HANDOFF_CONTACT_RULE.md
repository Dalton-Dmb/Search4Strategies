# AlphaIQ™ Successor Escalation Format

When owner/external intervention is genuinely required, report:

1. **Blocked artifact/milestone** — exact issue/module/gate.
2. **Missing input** — exact source, credential/access, decision or independent evidence needed.
3. **Why it cannot be inferred** — e.g. proprietary rule, licensing, release authority.
4. **Work already completed** — tests/adapter/scaffolding ready for the input.
5. **Work continuing in parallel** — non-blocked tasks.
6. **Minimal requested response** — the smallest concrete owner action needed.

Do not send a generic “shall I proceed?” message.
