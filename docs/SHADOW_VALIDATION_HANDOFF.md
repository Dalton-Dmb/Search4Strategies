# AlphaIQ™ Paper/Shadow Validation Handoff

Use the existing KPM-06 journal/validation contracts with genuine point-in-time feeds after strategy certification and evidence activation. Preserve decision timestamps, regime/strategy evidence, feature/config/model lineage, abstentions and later-attached outcomes.

The validation report should state observation period, instruments/timeframes, decision/abstention counts, strategy/regime distribution, outcome/excursion metrics, slippage/latency where observable, feed/broker incidents, reconciliation/restart events and unresolved anomalies. Compare shadow behavior with historical OOS expectations without assuming they must match.

Paper/shadow validation is a release gate and learning source, not permission for real-money execution.
