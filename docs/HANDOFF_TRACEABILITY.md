# AlphaIQ™ Handoff Traceability

Every material successor claim should point to repository/evidence artifacts:

- “implemented” → code + tests + commit/PR;
- “strategy certified” → source register + certification evidence;
- “historically validated” → dataset/evidence manifests + OOS report;
- “ML champion” → training/governance/calibration artifacts + approval;
- “shadow validated” → journal/validation report;
- “audited” → independent KPM-07 dossier;
- “deployable” → image/config/runbook + fresh-host reproduction;
- “LIVE authorised” → explicit owner release approval.

Do not use an earlier conversation, screenshot, branch name or issue title as sole evidence of completion.
