# AlphaIQ™ Handoff Status Update Rule

The handoff records a point-in-time project snapshot. When later work changes a pending item, update `PROJECT_FINALITY_STATUS.yaml` and `PROJECT_STATUS_AT_HANDOFF.md` only when repository or evidence artifacts support the new state. Include the relevant PR, manifest, report or audit reference in successor release records.

Keep historical handoff version/date intact so reviewers can distinguish the original transition snapshot from later completion evidence.
