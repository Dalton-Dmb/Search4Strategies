# AlphaIQ™ Independent Audit Handoff

The repository contains KPM-07 audit/readiness machinery, but final independent audit evidence cannot be self-authored by the implementation developer.

The reviewer should receive exact release commit/configuration, dataset/evidence manifests, certified strategy source references, OOS/robustness reports, ML governance artifacts if enabled, journal trace samples, paper/shadow report, risk/execution recovery tests and deployment manifest. Findings must be severity-ranked and traceable.

Open HIGH/CRITICAL findings block the applicable release. Reviewer independence must be recorded. Audit completion for research/paper/shadow does not silently grant LIVE authorisation; the owner release decision remains separate.
