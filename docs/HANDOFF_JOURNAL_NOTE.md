# AlphaIQ™ Journal/Observability Handoff Note

The journal is part of the evidence chain, not optional logging. Preserve correlation IDs and version lineage so a decision can be reconstructed with its timestamp, instrument/timeframes, feature snapshot, regime evidence, eligible/rejected strategies, arbitration, risk result, execution state and later outcome/excursions.

Structured operational logs and the analytical decision journal may have different retention/format needs, but neither should expose secrets. Restart/recovery must avoid duplicating decision/order state and must preserve traceability across process boundaries.
