# AlphaIQ™ Source & Data Licensing Handoff

Before incorporating third-party strategy code, indicators, datasets or event feeds, verify the applicable licence/usage terms and preserve required notices/attribution. Do not copy incompatible proprietary code merely because its behavior is useful.

For historical market/event data, record provider/source and permitted storage/reproduction. If raw redistribution is restricted, keep reproducible manifests/fingerprints and authorised retrieval/normalisation procedures rather than committing the raw dataset publicly.
